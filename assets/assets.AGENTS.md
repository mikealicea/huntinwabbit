# Source assets

Keep source artwork here when adding a new identity. The starter currently uses text branding and
has no raster logos or social cards. Serve optimized derivatives from `web/public/` rather than
large source files. Document source rights and reproducible export commands alongside future assets.

Next metadata belongs to [the root layout](../web/src/app/layout.tsx); feature presentation owns
rendered image dimensions and accessible labels. Decorative images must not duplicate a link's name.
Never include personal data in public imagery. Run web/documentation gates and inspect affected
layouts at mobile/desktop widths in both themes after introducing artwork.
